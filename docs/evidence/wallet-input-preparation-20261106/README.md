Native confirmations, maturity, current unspent inputs and no duplicate/forged witness values are required. The Native original/attempt barriers, restored observation-only rule and post-flush expiry checks remain authoritative. Preparation does not sign, deliver, broadcast or consume Stock; a route is quoted independently after confirmation.
